# Гібридний пошук і reranking (Результат 4)

**Конфігурація:** стратегія `hierarchical`, dense = `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (FAISS HNSW), BM25 = `rank_bm25.BM25Okapi`
(k1=1.5, b=0.75; токенізація: нижній регістр, стоп-слова, обрізання слів до 6 символів), злиття **RRF, k = 60**
(кандидати: топ-50 з кожного ретривера), reranker = `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` (cross-encoder) для **топ-30 → топ-5**.

Схема: `запит → pre-filter (type, sensitivity, date) → [BM25 top-50] + [dense top-50] → RRF → top-30 → cross-encoder → top-5`
