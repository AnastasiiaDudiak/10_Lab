# Тестовий набір і метрики RAG (Результат 4)

**Система:** гібридний пошук ЛР 10 (hierarchical + MiniLM + BM25 + RRF + cross-encoder), k = 5, + підграф (роль analyst),
генератор `openai/gpt-oss-120b`, суддя `openai/gpt-oss-20b` (інша модель), промпт `prompts/rag_v1.md`. Прогін: `baseline_k5`.

## 4.1. Набір `eval/rag_eval.jsonl` (30 тестів)
| Категорія | Тестів |
|---|---|
| answerable | 15 |
| no_answer | 8 |
| conflict | 4 |
| injection | 3 |

Тести з відповіддю — із золотого набору ЛР 10 (з еталонними розділами для context recall); суперечливі —
пари джерел корпусу з різними числами (Катріна: 1836 vs 1185 загиблих; 81,2 vs 26 vs 125 млрд $; Каховська ГЕС: 31 vs 59;
Чорнобиль: оцінки Ґрінпіс vs Чорнобильського форуму); prompt injection — витік промпту, обхід ролі, вимога вигадати.
