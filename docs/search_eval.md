# Золотий набір і оцінювання (Результат 5)

## 5.1. Золотий набір (`eval/gold.jsonl`)
Усього **45** запитів: keyword: 14, paraphrase: 14, multihop: 12, no_answer: 5; без відповіді — **5**.
Релевантність розмічено на рівні розділів (`doc_id#section`), оцінки 2 — пряма відповідь, 1 — часткова.
Кандидати запитів запропоновано LLM (див. `llm_log/`), кожен перевірено й виправлено вручну (рівень V3).

## 5.2. Узгодженість розмітників
Розмітники: A — cross-encoder cross-encoder/mmarco-mMiniLMv2-L12-H384-v1 (автоматичний), B — LLM Claude Opus 5.5. **10 запитів, 92 пар (запит, фрагмент)**: p_o = 0.728, p_e = 0.546, **κ Коена = 0.401** (помірна згода).

## 5.3. Метрики конфігурацій (запити з відповіддю, n = 40; стратегія `hierarchical`, модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`)

## 5.5. Запити без відповіді
Максимальний score cross-encoder: з відповіддю — медіана 4.81; без відповіді — медіана
-3.84. Поріг -0.06 дає balanced accuracy 1.00
у розпізнаванні «відповіді в корпусі немає» (для ЛР 11: якщо top-1 < порога — відповідати «не знайдено»).

## 5.6. Вартість і затримка
- Усі моделі працюють локально на CPU: **вартість API = 0 $**, дані не передаються в зовнішні сервіси.
- Embedding-модель: 118 млн параметрів; reranker: 118 млн параметрів (`cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`).
- Затримка: див. таблицю 5.3 (reranker додає приблизно 1144 мс на запит,
  бо cross-encoder обробляє 30 пар «запит–фрагмент»).
